# ========================================
# PIPELINE-SPECIFIC PARAMETERS
# ========================================

# Data Format Requirements:
# - Input: DICOM format
# - Output: BIDS format, NIfTI (.nii.gz)
# - TR: 2.0s (adjustable in scripts)
# - Slice order: Odd (adjustable in scripts)

# Processing Parameters Used:
# - Smoothing: 5mm FWHM (2.12 sigma)
# - High-pass filter: 100s (0.01 Hz)
# - Standard space: MNI152 2mm
# - Motion correction: MCFLIRT
# - Registration: FLIRT/FNIRT

# ========================================
# TROUBLESHOOTING NOTES
# ========================================

# Common Issues:
# 1. "FSL not found" - Ensure FSLDIR environment variable is set
# 2. "deno command not found" - Install deno via conda
# 3. "MRIQC failed" - Check memory allocation (increase --mem_gb if needed)
# 4. "Permission denied" - Make scripts executable: chmod +x *.sh
# 5. "No space left" - Ensure sufficient disk space for intermediate files

# Memory Management:
# - MRIQC: Uses --mem_gb 16 (adjust based on available RAM)
# - FSL: Can be memory intensive for large datasets
# - Consider using cluster computing for datasets >20 subjects
